## Reporting a Vulnerability

The Laravel Developer Toolkit team takes the security of this developer tool seriously. Because this extension executes code generation locally and operates directly on your project files, security and non-destructive operations are core design principles.

If you discover a security issue (e.g., path traversal vulnerability, improper sanitization, or unsafe file operations):

1. **Do not create a public GitHub issue.**
2. Send an email to the project maintainers at `[SECURITY CONTACT EMAIL]`.
3. Provide:
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Operating system and VS Code version.
4. Maintainers will acknowledge receipt within 48 hours and work on a fix promptly.
